# Fabrication release checklist (manual approval required)

- [ ] Requirements and revision are frozen
- [ ] ERC report reviewed; every exception documented
- [ ] DRC including schematic parity reviewed; every exception documented
- [ ] All symbols and footprints checked against authoritative datasheets
- [ ] Critical current, voltage, power and thermal calculations independently reviewed
- [ ] Return paths, grounding, decoupling, connector orientation inspected
- [ ] BOM and assembly variants checked, alternatives approved
- [ ] Gerbers, drills, drill map, board outline, fabrication drawing visually inspected
- [ ] Test points and bring-up plan approved
- [ ] Independent hardware auditor findings resolved or accepted by human
- [ ] Human explicitly authorizes release
